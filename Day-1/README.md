# Day 1 - Introduction to LLMs and First API Call

## Objective
Understand Large Language Models (LLMs) and make the first API call using Groq and LangChain.

## Project: AI Study Assistant
An interactive AI assistant that answers students' questions and explains concepts in simple language.

## Technologies Used
- Python
- Google Colab
- Groq API
- LangChain
- GPT-OSS 120B

## Implementation
1. Installed the required Python library.
2. Configured the Groq API key securely.
3. Initialized the Large Language Model.
4. Executed the first API call.
5. Developed an interactive AI Study Assistant.

## Key Learnings
- Basics of Large Language Models.
- API key management.
- LLM initialization.
- Sending prompts to an AI model.
- Generating and displaying AI responses.

## How to Run
1. Install the dependency: pip install langchain-groq
2. Run: python task.py
3. Enter your Groq API key when prompted.
4. Enter a question to receive an AI-generated response.

## Outcome
Successfully implemented and tested an interactive AI Study Assistant using Groq and LangChain.
