- Tool integration with AI agents

## Assignment – TripWise AI Travel Assistant

TripWise is an intelligent AI-powered travel assistant that provides personalized travel recommendations, estimated budgets and day-wise itineraries using RAG and conversation memory.

## Features

- Personalized destination recommendations
- Smart trip budget calculation
- AI-powered itinerary generation
- Travel knowledge retrieval using ChromaDB
- Semantic search using embeddings
- Thread-based conversation memory
- Interactive chatbot
- Independent traveler sessions

## Technologies Used

- Python
- LangChain
- LangGraph
- Groq LLM
- ChromaDB
- Google Colab

## Learning Outcomes

- Implemented conversation memory using thread IDs.
- Converted travel documents into vector embeddings.
- Stored and retrieved information using ChromaDB.
- Implemented RAG for knowledge-based responses.
- Integrated multiple custom tools into a single AI agent.

## Limitations

The application uses sample travel information and estimated costs rather than live travel data. Conversation memory is temporary, and real-time bookings are not supported.

## Conclusion

This assignment demonstrates how memory, RAG, vector databases and custom tools can work together to build an intelligent and personalized AI travel assistant.
